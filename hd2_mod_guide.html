★ CHAPTER 01 // INSTALLING MODS
Install
Mods
"A Helldiver without mods is just… a diver." — Probably someone

Before you can make mods, it helps to know how to use them. This chapter covers getting other people's mods onto your game using Nexus Mods and Arsenal — the two-step combo that runs the HD2 mod scene.

NEXUS MODS

Nexus Mods is the biggest mod hosting site on the internet. Think of it as a black market for game assets, but legal and run by people who love games.

  • 01
    Go to NexusMods.com
    Navigate to nexusmods.com and create a free account. You don't need a premium account to download mods (but it does make downloads faster if you enjoy waiting).
  • 02
    Find Helldivers 2 mods
    Search for "Helldivers 2" or browse the game page directly. There are audio mods, texture mods, cosmetic mods — the whole democratic buffet.
  • 03
    Note the "Vortex" button
    You'll see a "Mod Manager Download" button on mods. Don't use Vortex for HD2 — use Arsenal instead (see below). Just grab the manual download.

ARSENAL MOD MANAGER

Arsenal is the go-to mod manager specifically built for Helldivers 2. It handles dropping patch files into the right folders so you don't have to do it manually like some kind of level 1 Helldiver.

  • 01
    Download Arsenal Mod Manager
    Search "Arsenal Mod Manager Helldivers 2" on Nexus Mods and download it. Extract the zip wherever you want — your Desktop works fine, General Brasch won't judge.
  • 02
    Run Arsenal & point it at your game
    Launch Arsenal and tell it where Helldivers 2 is installed. On Windows this is usually:
    C:\Program Files (x86)\Steam\steamapps\common\Helldivers 2
    or on a secondary drive:
    X:\SteamLibrary\steamapps\common\Helldivers 2
  • 03
    Add mods
    Drag downloaded mod zip files into Arsenal, or use the "Add Mod" button. Arsenal will handle extracting the patch files into the correct location in the game's data folder.
  • 04
    Enable & launch
    Toggle mods on/off with the checkboxes in Arsenal, then launch the game. That's it. You are now a certified mod user. The Ministry is proud of your consumption.
⚠ IMPORTANT: GAME UPDATES
Game patches from Arrowhead can break mods. If the game updates and crashes, open Arsenal and disable all mods until mod authors update them. This is not a Terminid attack. Probably.

★ CHAPTER 02 // TOOLS SETUP

Setup
"A Helldiver without their weapons is just a corpse in a cool suit."

To create audio mods you need two things: Wwise (for converting audio formats) and the HD2 Audio Modding Tool (for actually replacing game audio). Both are free. Super Earth would never make you pay for democracy.

INSTALLING WWISE

Wwise is an industry-standard audio middleware tool from Audiokinetic. Helldivers 2 uses it to handle all in-game audio, and the modding tool uses it to convert your files into the game's format.

★ GOOD NEWS FROM THE MINISTRY
Wwise is completely free for non-commercial projects. You're not selling your Eagle-1 soundpack, are you? Good.
  • 01
    Create an Audiokinetic account
    Go to audiokinetic.com/en/download/ and make a free account. Yes, another account. The price of democracy is remembering passwords.
  • 02
    Download the Audiokinetic Launcher
    Download and install the launcher. It's like Steam, but for audio tools and significantly less distracting.
  • 03
    Install a version of Wwise
    In the launcher, click the Wwise tab on the left. Under "Install a New Version", pick the latest stable version and click Install. You don't need any optional plugins. Keep it lean.
  • 04
    Verify installation
    You should see your installed version appear under "Installed Versions" in the launcher. If you see it, congratulations — Wwise is deployed.
NEXT OBJECTIVE

AUDIO MODDING TOOL

This is the actual tool you'll use to swap audio in the game archives. It works alongside Wwise to handle format conversion behind the scenes.

  • 01
    Download the HD2 Audio Modding Tool
    Find it on the Helldivers 2 modding community resources (Nexus or the HD2 modding Discord). Download the .zip for your OS.
  • 02
    Extract the zip
    Extract anywhere you like. A dedicated mods folder is recommended:
    C:\HDMods\audio_modder\
  • 03
    Launch the tool
    Run audio_modder.exe (Windows) or audio_modder (Linux/MacOS). On first launch it will ask you to locate your game data folder.
  • 04
    Point it at Helldivers 2
    Navigate to your Helldivers 2 install folder and select it. Same path as before:
    C:\Program Files (x86)\Steam\steamapps\common\Helldivers 2
⚠ WWISE IS REQUIRED FOR AUDIO MODS
You only need Wwise if you're making audio mods. For text-only mods (renaming weapons etc.), Wwise is not needed. The tool will handle text without it.

LOADING GAME ARCHIVES

All of HD2's audio is stored in archive files inside the game's data folder. Each archive contains one or more sound banks, which contain the actual audio files. The modding tool is your key to these vaults.

Using the Search Bar (Easy Mode)

  • 01
    Click the search bar in the top left of the tool and type what you're looking for — weapon names, character names, stratagems, etc. ("Eagle 1", "Berserker", etc.)
  • 02
    A dropdown appears with matching archives. Double-click an entry to load it, or use arrow keys and press Enter.
  • 03
    Use the language dropdown on the right to filter results to a specific audio language (English, French, Japanese, etc.).

Loading Archives Manually (Hard Mode)

If you know the specific archive filename (from the Helldivers 2 Archive Labeling spreadsheet), go to File → Open → From HD2 Data Folder, type the archive name in the search box, and select it.

ACCEPTABLE AUDIO FORMATS

The tool can import audio from these formats — no conversion needed on your end:

.wav (linear PCM)
.mp3
.m4a
.ogg
.wem (Vorbis only)
⚠ WEM FILES: VORBIS ONLY
If you're using .wem files directly, they must be in Vorbis format. Other Wwise codecs will not work. You've been warned.

NAVIGATING SOUND BANKS

  • 01
    Once an archive loads, its contents appear in the Resource Panel (middle column). You'll see a tree of Sound Banks.
  • 02
    Click the arrow next to a Sound Bank to expand it and reveal its Audio Sources (the individual .wem files).
  • 03
    Double-click any audio source to play it and preview what it sounds like. Find the specific line you want to replace before touching anything.
★ PANEL GUIDE
Workspace Panel (left) — quick access to your mod folders.
Resource Panel (middle) — the loaded archive contents.
Info Panel (right) — details + controls for the selected file.

EXAMPLE: REPLACING EAGLE-1 VOICE LINES

We'll use Eagle-1 as our example. She has lots of lines, she's very chatty, and she probably won't notice if you swap a few of them.

Step 1 — Load the Archive

  • 01
    Type Eagle 1 in the Archive Search bar and select Eagle 1 (English) from the dropdown. Double-click to load it.
  • 02
    The archive contents appear in the Resource Panel. Find and expand the Eagle 1 (English) sound bank by clicking the arrow. Ignore the other banks for now.
  • 03
    Double-click audio sources to preview them until you find the exact line you want to replace. Write down its ID number — you'll need it.

Step 2 — Importing a Single File

  • 01
    Right-click the audio source you want to replace and select "Import Audio". Select your replacement file. Done. The file name doesn't matter for single imports.
  • 02
    Alternatively, just drag-and-drop your file directly onto the target audio source in the panel. Same result, fewer clicks.
  • 03
    Bonus trick: Select multiple audio sources with Shift-click or Ctrl-click, then right-click → "Import Audio" to replace ALL of them with the same file. Eagle-1 saying the same thing repeatedly? Valid strategy.

Step 3 — Importing Multiple Files

Replacing many lines at once? You need to name your files correctly so the tool knows which goes where.

Naming convention: Start every filename with the ID number of the audio it replaces.

1456960252248190624.wav
12574216746213182867.wav
5786867730735499085_here_comes_the_cavalry.wav

You can include extra text after the ID — as long as the filename starts with the correct ID, the tool will find it.

  • 01
    Get the ID: Right-click any audio source in the tool and choose "Copy File ID". Paste it as the start of your filename.
  • 02
    Batch import: Once your files are named, drag them all into the Resource Panel at once, or go to File → Import → Import Audio Files.
  • 03
    Modified audio sources will turn GREEN in the panel to confirm the replacement was successful.

Step 4 — Generate the Patch

  • 01
    Go to File → Write Patch. Choose a save location. The tool generates the patch file(s) for your mod.
  • 02
    Place the generated patch files in Arsenal or drop them directly into the game's data folder. Launch the game and enjoy your cursed creation.
⚠ REVERTING CHANGES
Changed your mind? Modified files are highlighted in green. Go to Edit → Revert All Changes to undo everything, or click the Revert button in the Info Panel to undo a single file.

EXAMPLE: CHANGING SHIP AMBIENCE

The ambient music aboard your Super Destroyer plays when you're hanging out between missions. Here's how to swap it for something that better matches your energy.

  • 01
    Search for Ship Music in the Archive Search bar and double-click the result to load it.
  • 02
    The archive contains two sound banks: Ship Music and Music. The ship ambience lives in both — modding either one saves changes to both automatically.
  • 03
    Expand the Music sound bank. The audio source ID for the ship ambience is:
    1524611437487953956
    Find it in the list and double-click to confirm you're replacing the right thing.
  • 04
    Name your replacement audio file starting with the ID:
    1524611437487953956_ship_ambience.wav
    Then drag-and-drop it into the Resource Panel. The entry will turn green.

MUSIC TIMING — THE IMPORTANT BIT

Unlike voice lines, music has timing metadata that controls how it loops, fades, and transitions. The tool automatically sets this based on your audio file's length, which works for most cases.

After importing your music, the tool auto-sets the duration to match your file length. For simple ship ambience replacement, this is all you need — the tool handles it.

If you want fine control over looping and fades, see Chapter 06: Advanced.

  • 05
    Once the audio is imported and looking green, go to File → Write Patch to generate your patch files. Save them somewhere sensible.
  • 06
    Load the patch via Arsenal or drop it in the game's data folder. Boot the game, get on your ship, and enjoy whatever chaos you've unleashed on your audio system.
⚠ MULTIPLE SEGMENTS MAY BE HIGHLIGHTED
When you change one audio source in a music archive, you may see multiple Music Segments and Tracks highlighted green. This is normal — it means the same audio is used in more than one place. You'll need to update timing in all highlighted segments if you're doing advanced edits.

This chapter covers the timing and volume systems that control how music plays in-game. The tool handles the basics automatically, but if your music loops weirdly or cuts off too early, this is where you fix it.

MUSIC TIMING PARAMETERS

Music in HD2 has two layers: Music Tracks (the audio clip level) and Music Segments (the sequence/loop level). Each has its own timing controls.

Music Track Parameters

Parameter What it does
Duration (ms) How long the track plays. Usually set to the full length of your audio. The track cuts off at this time even if audio is still playing.
Play At (ms) When the track starts playing within its parent Segment. 0 = immediately. Negative values start mid-clip. Useful for layering tracks.
Start Trim (ms) Cuts the beginning off. 1000ms = first second is silent. Use to skip intros.
End Trim (ms) Cuts the end off. 1000ms = last second is removed. Use to trim outros.

Music Segment Parameters

Parameter What it does
Duration (ms) How long the segment plays. If your audio is shorter, the segment plays silence for the remainder. If longer, audio cuts off.
End Fade-In (ms) Transition marker — aligns with the previous segment's Start Fade-Out. Set this to when your music finishes fading in.
Start Fade-Out (ms) Transition marker — aligns with the next segment's End Fade-In. Set this to when your music starts fading out.
★ SIMPLE LOOPING MUSIC? IGNORE MOST OF THIS.
For simple ship ambience replacement with no fancy transitions, just make sure Duration matches your audio length and leave everything else at defaults. The tool sets this automatically on import.

ADJUSTING TIMING

  • 01
    Go to View → Hierarchy to switch to Hierarchy View. This shows Music Tracks and Segments instead of raw audio sources.
  • 02
    Find your modified music by looking for the highlighted (green) entries. Click a Music Segment or Music Track to see its timing info in the Info Panel.
  • 03
    Edit the values directly in the Info Panel fields and click Apply. Without clicking Apply, nothing saves.
  • 04
    CRITICAL: If multiple Segments/Tracks are highlighted, update all of them. Audio shared across multiple tracks needs consistent timing in each one or you'll get weird results.

VOLUME GRAPHS

Many Music Tracks have a volume graph that adjusts the audio volume over time (used for dynamic mixing in-game). You can edit these manually.

The volume graph's Y-axis is a percentage adjustment from baseline:
0% = no change (plays normally)
-100% = completely silent
Positive values = louder than baseline

Editing the Graph

  • +
    Add a point: Left-click on an empty area of the graph.
  • ✥
    Move a point: Left-click and drag an existing point.
  • ✕
    Remove a point: Right-click on a point.
  • ✓
    Save changes: Click Apply. Don't forget this step or nothing saves.
⚠ PATCH MODIFICATION RULES
Do NOT write a patch of a patch.
Do NOT use Save with game archives — only with patch files.
To add new audio to an existing patch: open the original archive first, import the patch file, then add your new audio, then Write Patch.
