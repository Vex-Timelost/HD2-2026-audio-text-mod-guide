Helldivers 2 · Community Guide

How to Install & Create Mods

A step-by-step guide covering how to install mods using Nexus Mods and Arsenal Mod Manager, as well as how to create your own audio and text mods for Helldivers 2.

Your progress 0 / 0 steps complete
01

Installing Mods

Download Arsenal Mod Manager
Get Arsenal Mod Manager from Nexus Mods. This is the tool you'll use to manage all your Helldivers 2 mods. Install it to a location outside your game folder.
Point Arsenal to your game folder
Open Arsenal Mod Manager and set your Helldivers 2 game directory. It's usually located at:
default path
C:\Program Files (x86)\Steam\steamapps\common\Helldivers 2
Browse and download a mod from Nexus
Go to nexusmods.com/helldivers2 and find a mod you want. Click "Mod Manager Download" — this will send it directly to Arsenal if it's set up correctly.
Tip: You need a free Nexus Mods account to download files.
Enable the mod in Arsenal and launch
In Arsenal, check the box next to the mod to enable it. Then launch the game through Arsenal (not Steam directly) to make sure the mods are loaded.
02

Creating Audio Mods

Note: Audio mods replace in-game sounds with your own audio files. Common uses include custom weapon sounds, music, or voice lines.
Find the audio file you want to replace
Use a tool like HD2 Data Explorer to browse the game's packed files and locate the audio file you want to swap out. Audio files in HD2 are typically in .wem format.
Prepare your replacement audio
Convert your audio file to the .wem format using Wwise or a WEM converter. Match the length and sample rate of the original when possible to avoid issues.
recommended format
Format: .wem (Wwise Encoded Media) Sample rate: match original (usually 44100 Hz) Channels: match original (mono or stereo)
Rename your file to match the original
The game loads audio by file ID. Rename your converted file to exactly match the original file's name/ID so the game picks it up as a replacement.
Package and load via Arsenal
Place your file in the correct folder structure, zip it up, and import it into Arsenal Mod Manager. Enable it and test in-game.
03

Creating Text Mods

Note: Text mods let you change in-game strings like item names, descriptions, UI labels, and mission text.
Extract the game's text files
Use HD2 Data Explorer to find and extract the localization files. These contain all in-game text and are usually stored in a structured format tied to the game's language settings.
Edit the text values
Open the extracted file in a text editor. Find the string you want to change by searching for keywords. Edit only the value, not the key name.
example
# Before "WEAPON_NAME_RAILGUN": "RS-422 Railgun" # After "WEAPON_NAME_RAILGUN": "Big Zapper 9000"
Repack and load via Arsenal
Save your edited file, repack it into the correct format, and import it into Arsenal Mod Manager. Text mods are some of the safest mods to make since they don't affect gameplay logic.
Tip: Always keep a backup of the original file before editing.
